Real-time multiplayer ping pong game with synchronized gameplay and competitive mechanics. Built with WebSocket-based state synchronization enabling real-time interactions between players with sub-100ms latency.

Key features include real-time paddle synchronization, ball physics prediction, matchmaking system, and ranked competitive play with ELO-based scoring.
